# Forge BPMN

View and edit BPMN 2.0 diagrams in IntelliJ IDEA. Camunda Modeler-style canvas, properties panel, XML round-trip, and basic syntax lint.

Generated by **Forge BPMN**. Target: IntelliJ IDEA Community 2024.3+ (sinceBuild 243).

## What you get

- `.bpmn` file type (XML language, diagram editor first)
- Bottom **XML** / **BPMN** buttons under the editor — one-click switch, round-trip through the document
- Camunda Modeler-style canvas via bundled **camunda-bpmn-js** Cloud modeler (properties panel, palette, XML round-trip)
- XML annotator + inspection for basic BPMN syntax lint (well-formed XML, start/end events, disconnected nodes, duplicate ids, unnamed tasks)
- GitHub Actions: build on push/`main` only (`dev` is local); publish on GitHub Release

## Develop locally (no zip)

Work on **`dev`**. Actions will not run there.

1. Clone, `git checkout dev`.
2. IntelliJ **File → Open** this folder.
3. Run **Run Plugin**. A second IDE opens with the plugin loaded.
4. Open `examples/refund-request.bpmn`.

See **[INSTALL.md](INSTALL.md)**.

JDK 17+. First import downloads Gradle 8.13 and the IntelliJ SDK.

## Build a distribution zip (optional)

```
gradle buildPlugin
```

Output: `build/distributions/`.

## Publish to JetBrains Marketplace

See **[MARKETPLACE.md](MARKETPLACE.md)**. Short path:

1. Push this project to GitHub.
2. Add secrets: `PUBLISH_TOKEN`, `CERTIFICATE_CHAIN`, `PRIVATE_KEY`, `PRIVATE_KEY_PASSWORD`.
3. Upload the **first** version by hand at [plugins.jetbrains.com/plugin/add](https://plugins.jetbrains.com/plugin/add) (`build/distributions/*.zip`).
4. Later versions: GitHub → Releases → publish tag `v0.3.2`. The **Publish** workflow runs `gradle publishPlugin`.
